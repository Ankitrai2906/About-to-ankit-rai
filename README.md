# Ankit Rai — Personal Portfolio

A premium one-page React portfolio starter for Ankit Rai.

## Run locally

1. Install Node.js (LTS).
2. Open terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Before publishing
- Replace `your-email@example.com` with your real email in `src/main.jsx`.
- Replace project descriptions/links with exact live demos when available.
- Add your professional photo if desired.
- Run `npm run build` before deployment.

## Deploy
This can be deployed to Vercel, Netlify or GitHub Pages after the project is pushed to GitHub.
